## First hardware run

The first test launched the 32-bit armhf executable successfully, then exited
with signal 11 (`exit_code=139`). The preserved log is
`hardware-results/maptest-run1.log` with SHA-256
`d009f541e5a8555c0f93d7d73df9e13e72182100a6922766d314e03151727fc0`.

The fault was in the mapper, not in ArkOS or the Android libraries. After
copying an ELF image, the mapper protected its entire reservation and then
read the program-header table from that protected memory. The corrected build
keeps gaps inaccessible, grants temporary write access only to loadable
segments, and applies each segment's final permissions afterward. It also
prints progress without buffering so a future failure identifies the module.

## Run procedure

1. Safely eject the card, boot the R36S and allow Ports to refresh.
2. Launch **NFS Most Wanted - Mapper Test** once.
3. If the game loop appears, exercise menus/controls/audio, then press
   **Back+Start together**. Otherwise the test stops after about five minutes.
   A PASS or FAIL message then appears for ten seconds.
4. Shut down cleanly, return the card to the computer, and read
   `/roms/ports/nfsmw-maptest/maptest.log`.

The consolidated test attempts all remaining runtime gates in one process and
records every completed checkpoint before the first target fault.
